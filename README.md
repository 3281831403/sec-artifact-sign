制品仓库接受多签之后，只要凑够两个签名就放行，其中一个早就过期了也没人管：多签名必须达到策略给出的阈值，且每个签名都落在自己的有效期内，两端都算有效；签名者必须出现在授权名单里；同一签名者重复签名只计一次；每个签名都必须绑定当前制品的摘要；过期签名不计入阈值；阈值只能来自校验策略而不是签名文件本身；批量校验时每个制品各自独立判定。无论签名以什么顺序排列，校验结果都不变；同一个制品重复校验，结果也保持不变。
